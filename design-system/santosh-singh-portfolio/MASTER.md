# Orbit Lab / Dark futuristic portfolio

## Design intent

A personal portfolio shaped like a low-lit instrument lab. It presents an AI/ML student who turns dense inputs into practical tools through bold typography, precise frames, a subtle technical grid, and luminous cyan/violet signals. Keep the work easy to inspect and the person easy to remember.

## Palette

- Near-black field: `#080B14`
- Raised surface: `#101725`
- Hover surface: `#182338`
- Cool white text: `#EAF3FF`
- Muted blue-gray text: `#A6B6CC`
- Deep slate rule: `#29364C`
- Electric violet: `#B69CFF`
- Luminous cyan: `#54F1E5`

Use near-black as the main field with layered navy surfaces. Keep body text cool white, use cyan for primary actions, and violet for secondary signals and selected headline accents. Put dark ink on both neon accents. Keep natural color in the portrait and genuine project footage.

## Typography

- Display: Anton, compressed and oversized.
- Accent: IBM Plex Serif Italic for selected phrases.
- Body: DM Sans.
- Metadata: Space Mono, used sparingly.

Main headlines stay in sentence case. Body copy remains readable and conversational.

## Composition

Use a magazine grid with a slim metadata line and plain navigation, a large left-aligned headline, and a midnight portrait plate featuring Santosh's real photo. Set a small interactive orbital instrument into the portrait plate. Follow with a crisp subject strip, an asymmetrical featured project spread, and a project index. Continue with a midnight interactive workbench, a compact learning timeline, and a quiet contact panel.

Give each project its own graphic plate: paper and quiz fragments for the study tool, a review window for local code review, a trace plot for the model pipeline, and crop marks with signal tiles for image analysis. Let visitors rotate the artifact previews, and give the study tool a separate three-stage source-to-review explainer. Keep project facts and technology lists grounded in the source data.

## Graphic language

Use a dark layered field, structured frames with lightly rounded controls, visible rules, hand-built vector illustrations, and chart-like forms. Set restrained cyan and violet glows against the dark surfaces, with a faint technical grid and generous open space. The orbital centerpiece uses CSS perspective and paths so it stays light, responsive, and integrated with the portrait. Add purposeful 3D interactions for the project workflow, network map, classifier, skill constellation, and project artifacts. Avoid soft glass, generic laptop mockups, robot heads, circuit boards, and fake metrics.

## Interaction and access

Make every navigation item and project row keyboard reachable with a visible focus state. Let the orbital paths move slowly and react to pointer tilt. Make 3D scenes respond to drag and arrow keys, provide a reset control, and keep all information available without motion. Show the AI/ML student identity through the interactive project map, real work, and learning timeline. Use a deliberate stacked mobile composition and respect reduced-motion preferences. Maintain strong contrast.
