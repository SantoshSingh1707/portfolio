# Night Signal — Santosh Singh

## Design intent

A personal portfolio shaped like a dark signal instrument: direct, tactile, graphic, and carefully composed. The site is an exhibition catalogue for a computer science student who turns dense inputs into practical tools. Keep the work easy to inspect and the person easy to remember. Let a small orbital gyroscope be the moving object that carries the visual identity.

## Palette

- Midnight field: `#0C0E13`
- Warm light: `#EEECE5`
- Signal blue: `#7886FF`
- Signal orange: `#F17A5A`
- Field citron: `#D1ED79`

Use midnight as the main field, warm light for type and rules, signal blue for emphasis, orange for small markers, and citron for compact high-contrast details. Reserve pale stock for document fragments inside project artwork.

## Typography

- Display: Anton, compressed and oversized.
- Accent: IBM Plex Serif Italic for selected phrases.
- Body: DM Sans.
- Metadata: Space Mono, used sparingly.

Main headlines stay in sentence case. Body copy remains readable and conversational.

## Composition

Use a magazine grid with a slim metadata line and plain navigation, a large left-aligned headline, and a midnight portrait plate featuring Santosh's real photo. Set a small interactive orbital instrument into the portrait plate. Follow with a dark subject strip, an asymmetrical featured project spread, and a project index. Continue with a deep blue notes section, a compact learning timeline, and a quiet contact panel.

Give each project its own graphic plate: paper and quiz fragments for the study tool, a review window for local code review, a trace plot for the model pipeline, and crop marks with signal tiles for image analysis. Keep project facts and technology lists grounded in the source data.

## Graphic language

Use screen-print inspired color fields, restrained grain, thin registration marks, hand-built vector illustrations, and chart-like forms. Keep project artwork bright enough to read against the dark page. Use square edges, hairline dividers, and generous open space. The 3D centerpiece uses CSS perspective and orbital paths so it stays light, responsive, and integrated with the portrait. Avoid repeated rounded cards, generic glow orbs, generic laptop mockups, robot heads, circuit boards, and fake metrics.

## Interaction and access

Make every navigation item and project row keyboard reachable with a visible focus state. Let the orbital paths move slowly and react to pointer tilt. Keep other hover movement small and purposeful. Use a deliberate stacked mobile composition and respect reduced-motion preferences. Maintain strong contrast.
