# Night Signal / Brutalist portfolio

## Design intent

A personal portfolio shaped by dark brutalist graphics: direct, tactile, and carefully composed. The site is an exhibition catalogue for an AI/ML student who turns dense inputs into practical tools. Oversized typography, hard borders, visible rules, and a single safety-orange signal carry the identity. Keep the work easy to inspect and the person easy to remember.

## Palette

- Charcoal field: `#101010`
- Raised surface: `#191919`
- Warm white: `#F2EEE6`
- Muted warm gray: `#B0ACA4`
- Rule and border: `#68635A`
- Safety orange: `#FF6B35`
- Orange hover: `#FF895D`

Use charcoal as the main field, warm white for type, warm gray for supporting text, and orange for emphasis and interactive states. Orange surfaces use charcoal text. Keep natural color in the portrait and genuine project footage; reserve warm light panels for interface details inside project artwork.

## Typography

- Display: Anton, compressed and oversized.
- Accent: IBM Plex Serif Italic for selected phrases.
- Body: DM Sans.
- Metadata: Space Mono, used sparingly.

Main headlines stay in sentence case. Body copy remains readable and conversational.

## Composition

Use a magazine grid with a slim metadata line and plain navigation, a large left-aligned headline, and a charcoal portrait plate featuring Santosh's real photo. Set a small interactive orbital instrument into the portrait plate. Follow with a dark subject strip, an asymmetrical featured project spread, and a project index. Continue with a charcoal notes section, a compact learning timeline, and a quiet contact panel.

Give each project its own graphic plate: paper and quiz fragments for the study tool, a review window for local code review, a trace plot for the model pipeline, and crop marks with signal tiles for image analysis. Keep project facts and technology lists grounded in the source data.

## Graphic language

Use hard color fields, heavy square frames, visible rules, hand-built vector illustrations, and chart-like forms. Keep project artwork bright enough to read against the dark page. Use offset hard shadows and generous open space. The orbital centerpiece uses CSS perspective and paths so it stays light, responsive, and integrated with the portrait. Avoid repeated rounded cards, soft glass, generic laptop mockups, robot heads, circuit boards, and fake metrics.

## Interaction and access

Make every navigation item and project row keyboard reachable with a visible focus state. Let the orbital paths move slowly and react to pointer tilt. Keep other hover movement small and purposeful. Show the AI/ML student identity through the interactive project map, real work, and learning timeline. Use a deliberate stacked mobile composition and respect reduced-motion preferences. Maintain strong contrast.
