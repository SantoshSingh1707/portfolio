# Stitch Design Brief — Santosh Singh Portfolio

Historical initial Stitch brief. The user has since directed the implementation toward a dark futuristic system. `MASTER.md` is the current palette and visual authority: near-black/navy surfaces, cool white text, luminous cyan actions, and violet signals. This document preserves the first screen-generation prompt for reference.

## Shared creative direction

**Brand Name:** Santosh Singh.

**Brand Description:** Santosh Singh is a Computer Science and Engineering student at DIT in Dehradun, Class of 2027. His portfolio presents practical experiments in retrieval-augmented learning, local code review, reproducible machine-learning workflows, and computer-vision explainability. It serves students, recruiters, and companies. The tone is student-first, curious, direct, tactile, and honest about work still in progress.

**Aesthetic Direction — approved Invention Gate metaphors, verbatim:**

1. “The portfolio feels like a dark workbench: square, tactile surfaces, ruled marks, and one orange indicator that makes the next useful action easy to find.”
2. “The work feels like marked-up study pages: source documents, code notes, model plots, and small annotations gathered into a usable record.”
3. “The satisfying moment is when a result stops being a label and starts showing the evidence or steps behind it.”

At rest, translate these into an asymmetric editorial grid, a low-lit instrument bench, precise rules, layered project evidence, visible labels, restrained project plates, and a clear orange signal. Use generous dark negative space. Project visuals should look like carefully composed evidence from actual work: document fragments and quiz cards for the study tool; a private code-review pane for the local agent; an experiment trace and pipeline stages for the house-price workflow; and image crops with inspectable signal marks for TruthLens AI.

**Negative constraints:** No robot heads, glowing brains, circuit-board clichés, stock AI gradients, generic laptop mockups, glassmorphism, blurry translucent cards, decorative particle clouds, fake performance metrics, unreadably tiny labels, or orange accents that do not identify a real action or evidence point. Avoid rounded-card dashboards; keep corners square and frames deliberate. Do not imply unsupported project results, experience, or employment outcomes.

**Typography Guidance:** Use Anton for oversized, condensed, sentence-case display headlines; IBM Plex Serif Italic for only a few selected emphasis phrases; DM Sans for body copy and controls; and Space Mono for short metadata labels. Make display type dominant and high contrast, with generous line height and descender room. Keep body copy comfortably readable. The scale should feel editorial and ambitious, not like a software admin dashboard.

**Color Direction:** Preserve the existing Night Signal identity exactly: page charcoal `#101010`, raised surface `#191919`, warm white `#F2EEE6`, muted warm gray `#B0ACA4`, rule `#68635A`, signal orange `#FF6B35`, orange hover `#FF895D`. Orange surfaces use charcoal text. Keep body text at strong contrast and reserve orange for key signals and interactive states.

**Icon System:** Use Lucide icons exclusively. Keep icons sparse and functional.

**Shared Navigation:** A slim charcoal navigation bar with the Santosh Singh wordmark on the left and the small caption “Student in progress.”; center links in this order: Home, Projects, Lab, About, Contact; right-side outlined link “My résumé” with a Lucide ArrowUpRight icon. On mobile, collapse the center links behind a menu button and keep the résumé action accessible.

**Shared Footer:** A full-width charcoal footer with a top invitation “The next good thing starts with hello.” and large “Let’s talk.” link on the left; a short “Have an idea, a question, or a project worth building?” prompt and “Back to the top” link on the right; then a ruled row with Home, Projects, Lab, About, Contact; a brand row for SANTOSH SINGH and “AI/ML student. Learning by building.” plus GitHub, LinkedIn, LeetCode, and Email links; and a compact bottom row with copyright, Dehradun, India, and “Still learning. Still making.”

**Device Target:** Design each screen at desktop width 1440px with mobile-responsive awareness. Show a believable 375px layout in the responsive structure: stacked columns, readable type, touch-sized controls, no horizontal overflow. The screenshot target remains desktop.
