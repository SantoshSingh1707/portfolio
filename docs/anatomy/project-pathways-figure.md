# Project Pathways Figure

## Size

**Hero**: a 100+ part physical patchbay, built with the Anatomy turning kit. The complete neural routing panel turns around a vertical axis; selected project paths carry a restrained moving signal.

## Concept

The **project pathway patchbay** treats each portfolio category as an input socket, each layer of connected nodes as a routing bank, and each project outcome as an output terminal. The object turns so its board thickness, brackets, sockets, and fasteners read as real depth.

## Truth and limits

The routes are a portfolio navigation metaphor. They do not claim to show a project's private model architecture, runtime telemetry, learned weights, or measured performance. Project names and descriptions come from the existing portfolio data.

## Interaction

- Four existing mode buttons select the project pathway and illuminate its source, representative nodes, and output route.
- The complete patchbay makes a slow, continuous turn while it is visible and idle.
- Drag and left/right keys steer the same turn. A reset returns to the home angle; pause stops the idle turn.
- Reduced motion starts in a still pose and disables the moving trace. Drag and buttons remain usable.
- The inspector continues to show the verified project description and the input, process, and output labels.
